# 工作流架构

律师 AI 助理不是一个“万能提示词”，而是一条带责任人的流水线：

```text
需求
  ↓
任务卡：范围、材料、边界、输出、审核、证据
  ↓
专业 Skill：只处理其专业范围
  ↓
人工审核：助理核形式，律师核事实、法律和策略
  ↓
成果验收：文件存在、内容复读、下游回执
```

## 为什么先做任务卡

律师工作中的错误往往不是模型不会写，而是对象、版本、期限或完成标准没有说清。任务卡把输入和责任前置，减少“做错文件”“漏看附件”“把草稿当终稿”等问题。

## 为什么需要专业 Skill

合同审查、庭审准备、证据编排和文章写作的检查逻辑不同。每个 Skill 应只承担一类清楚的任务，并明确需要读取哪些材料、如何输出和哪里必须停下来交给律师。

## 为什么完成回执单独设计

AI 写完文档不等于已经发送，打开平台不等于已经提交。把完成证据单独设计，可以让团队在交接时知道任务到底到了哪一步。
