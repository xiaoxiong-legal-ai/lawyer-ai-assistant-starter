# 开始这里

## 1. 选择测试环境

使用支持本地 Skill 或自定义指令的 AI 助理。首次运行不要连接真实案件文件夹、邮箱、法院平台、支付账户或团队通讯工具。

## 2. 安装 Skill

把 `skills/` 下三个完整文件夹复制到你的 AI 助理 Skill 目录。不要只复制 `SKILL.md`，还要保留 `references/` 和 `agents/`。

不同工具的安装位置不同；如果工具没有 Skill 目录，可以先把 `SKILL.md` 作为项目指令导入，并把引用文件一起提供。

## 3. 启动虚构测试

依次使用：

1. `lawyer-ai-task-card`：整理任务；
2. `contract-review-starter`：审查虚构合同；
3. `legal-output-verifier`：验收结果。

测试材料位于 `examples/fictional/`。不要把虚构示例中的名称替换成真实客户后直接对外使用。

## 4. 人工验收

按照 `tests/README.md` 检查：是否识别材料缺口、是否引用条款、是否区分事实和推断、是否设置律师审核点、是否避免虚报完成。

## 5. 再接入真实工作

只有在虚构测试通过后，才考虑接入真实材料。正式接入前至少完成：

- 客户授权和保密评估；
- 本地或受控存储；
- 不同客户材料隔离；
- 高风险动作确认；
- 律师终审；
- 文件与平台回执核对。
