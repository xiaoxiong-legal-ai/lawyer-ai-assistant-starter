# 验收矩阵

| 成果类型 | 最低证据 | 不能替代完成证据的内容 |
|---|---|---|
| 摘要或分析 | 已读取的来源范围、输出正文、遗漏说明 | 只读取文件开头或只写结论 |
| 文书 | 可重新打开的目标文件、内容复读、版式检查 | 仅有生成脚本或临时草稿 |
| 金额计算 | 计算口径、输入数据、复算结果 | 只有最终金额 |
| 状态更新 | 原始记录、更新后记录、时间 | 口头说“已经记了” |
| 上传或发送 | 目标对象、平台状态、回执或记录 | 打开上传页、点击按钮前的截图 |
| 归档、删除或权限 | 精确对象、授权、变更后状态、恢复方案 | 仅执行本地命令或看到确认框 |

## 层级规则

- 纯对话摘要或分析：文件层可为 `N/A`，但内容层必须保存对话正文、来源范围和遗漏说明；
- 明确内容错误：`FAIL`；
- 因缺材料或授权无法核验：`BLOCKED`；
- 明确不在任务范围：`N/A`；
- 全部适用关键项通过：`PASS`。

任何分层 `PASS` 都不自动等于整体完成。合同初筛内容通过时，签署状态仍可能为 `BLOCKED` 或 `NEEDS_CONFIRMATION`。
