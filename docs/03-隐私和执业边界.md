# 隐私和执业边界

## 数据最小化

只提供完成当前任务所必需的材料。能用摘要解决的，不上传整卷；能用虚构样本测试的，不使用真实客户材料。

## 客户隔离

不同客户和案件使用独立文件夹、独立任务卡和独立会话。任何批量处理前先建立文件地图，避免把甲案材料带入乙案。

## 法律依据

法律、司法解释、政策和平台规则可能变化。需要引用时，应从当前有效的权威原文核对，不依赖模型记忆，也不把检索摘要当正式依据。

## 人工节点

以下内容不得无人值守：

- 最终事实认定和证据评价；
- 诉讼、仲裁、谈判和商业策略；
- 请求、抗辩、金额、期限和法律结论；
- 对客户、对方、法院、仲裁机构或公众的发送；
- 提交、付款、发布、权限、删除和结案。

## 完成状态

没有真实证据时，使用“草稿”“待核”“待提交”“待回执”，不要使用“已完成”。如果下游平台状态无法核对，应保留阻塞状态并交由人员处理。
