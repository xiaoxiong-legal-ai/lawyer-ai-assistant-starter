# 律师 AI 助理 Starter

一套可以直接下载、安装和试运行的律师 AI 工作流体验包。它不是课件，也不是提示词合集，而是把律师任务拆成“任务卡—专业处理—人工审核—完成回执”的可执行方案。

当前版本：`v0.1.0`

## 你会得到什么

- `lawyer-ai-task-card`：把口头指令变成可执行、可验收的任务卡；
- `contract-review-starter`：用虚构或匿名化合同体验结构化审查；
- `legal-output-verifier`：检查文件、内容和下游回执，避免把“做了”误报成“完成”；
- 4 份可复制模板；
- 1 套完全虚构的合同审查示例；
- 安装、隐私和测试说明。

## 30 分钟快速体验

1. 下载本仓库。
2. 按 [开始这里](docs/01-开始这里.md) 安装三个 Skill。
3. 打开 [虚构软件采购合同](examples/fictional/虚构软件采购合同.md)。
4. 把 [虚构合同审查任务卡](examples/fictional/虚构合同审查任务卡.md) 连同合同交给支持 Skill 的 AI 助理。
5. 使用 `legal-output-verifier` 验收输出。

## 目录

```text
skills/       三个入门 Skill
templates/    任务卡、核校、回执与测试模板
examples/     不含真实客户信息的虚构案例
docs/         安装、架构与安全边界
tests/        人工验收用例
```

## 适用范围

本项目适合律师、律师助理和律所管理者用于个人试运行。它不会替代执业律师对事实、证据、法律和策略的最终判断，也不应直接连接真实案件库后无人值守运行。

首次测试请只使用虚构材料。处理真实材料前，请先完成脱敏、权限隔离、人工复核和完成回执设计。
