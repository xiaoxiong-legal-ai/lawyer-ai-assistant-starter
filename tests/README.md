# Starter 人工验收

使用虚构示例完成一次运行后，检查以下项目：

- [ ] 任务卡区分执行状态和成果状态，明确了材料缺口、安全范围、禁止事项、人工审核和完成证据；
- [ ] 合同审查按主体、交易、履行、责任、争议解决展开；
- [ ] 每项主要风险引用了条款或指出缺失；
- [ ] 没有虚构法条、判例、身份或履行事实；
- [ ] 输出没有声称“合同可以直接签署”；
- [ ] 验收器区分文件、内容和下游三层；
- [ ] 缺少材料时标为 `BLOCKED`，明确错误标为 `FAIL`，不在范围标为 `N/A`；
- [ ] 缺少回执时没有写成已发送、已提交或已完成；
- [ ] 所有样本均为虚构，不含真实客户信息。

任一高风险项出现明确错误时，整体结论为 `FAIL`；因材料或授权缺失无法核验时为 `BLOCKED`。修复或补齐后重新测试。
